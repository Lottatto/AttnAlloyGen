# AttnAlloyGen
Code and data for the paper "Ultra corrosion-resistant magnesium alloys by interpretable generative artificial intelligence" (Nature Communications, 2026).

- `Data`: datasets used in the paper
- `Weights`: trained model weights
- `Extraction`: LLM extraction and evaluation
- `Model`: CombinedNet training and baseline comparison
- `Generation`: WAE generation and acquisition strategy comparison
- `ActiveLearning`: active learning iterations
- `Interpretability`: SHAP and attention analysis

Set the file paths at the top of each script before running.
